## 1. 本版目标与边界

本版取消固态储氢床、床体供热支路和气固切换机构，采用采购PEM电堆、纯气态储氢、空气供给、单一电堆液冷回路、DC/DC和辅助电池。

**唯一已明确的功率硬约束是对外净输出5 kW。**电堆毛功率必须支付转换损耗和全部计入模型的辅机耗电。旧报告的节数、气固比例、整机85 kg、170 L以及120 s建立气路的定义均不继承。

| 输入 | 本版采用 | 性质 |
|---|---|---|
| 对外连续功率 | 5 kW DC | 用户要求；若改AC需增加逆变损耗 |
| 输出母线 | 48 V，额定约104.2 A | 工程假设，未冻结 |
| 满载续航 | 4 h | 沿用工作假设，可调整 |
| 冷启动环境 | −30℃完全冷浸 | 目标工况，冷浸时间待定 |
| 冷启动时间 | 尽可能120 s；分别记录电池对外供电和电堆建立净输出 | 未证明 |
| 稳态散热工况 | 4000 m、+35℃ | 本版设计假设；不代表电堆已有高原认证 |
| 气瓶额定研究点 | 35 MPa绝压、15℃均温充装状态 | 容量计算参考点；实际充装遵守认证瓶参数 |
| 最低可用压力 | 2 MPa绝压、−30℃ | 调压器输入下限假设 |

“5 kW连续输出”不包括电池长期补足电堆功率缺口。电池启动后消耗的电量还需要额外发电余量恢复；本版4 h预算没有包含整段运行中的电池充电任务。

## 2. 功能拓扑

```text
认证气瓶A/B → 各自隔离/切断/安全附件 → 分级调压 → 低压氢路 → 电堆阳极
                                                          ↓
                                               排水/吹扫 → 规定安全排口

空气滤芯 → 鼓风机 → 必要的调温/加湿 → 阴极 → 冷凝水管理/排气

电堆 → 小循环/旁通阀 → 散热器 → 主泵 → 电堆
         ↑ 保温与启动加热       ↑ 膨胀/排气/净化支路

电堆 → 单向DC/DC → 48 V母线 → 外部负载
辅助电池 ↔ 双向DC/DC ────┘
独立安全链/控制器 → 阀、风机、泵、加热器、DC/DC
```

高压排放、低压工艺吹扫和阴极排气的压力、流量与背压限制不同，不能默认汇成同一根细管。图中仅定义功能，不作为施工P&ID。

## 3. 未知量与闭合条件

设计问题本来欠定：没有堆极化曲线、泵风机图谱、散热器性能面和气瓶型号，5 kW不能唯一决定所有部件尺寸。本版引入显式假设，求得一组可复算的初步解，再做敏感性分析。

主未知量为：

- 电堆电流 I；
- 散热器迎风面积 A；
- 冷却液质量流量 m_c。

由三项等式联合求解：

1. 净电功率等于5000 W；
2. 散热器排热等于进入冷却液的热量；
3. 冷却液温升等于5 K。

氢耗、空气流量、风机/泵功耗、气瓶水容积和管径从解中派生。电池、电控箱等缺少定型资料，只给预算及空间占位，不假称由三条方程唯一求出。

### 3.1 采购电堆参考平台

以2026-09-21归档的H-WCS-SP-7K为参考：119节、活性面积200 cm²、80 A、约90 V、公开功率7.1 kW、外形242×200×550 mm、约28 kg。采用现有平台只是为了提供实体尺度。

公开工作环境5～35℃，测试条件65℃、常压及阴阳极100%RH。**这些数据不证明4000 m、60℃冷却出口或−30℃启动时仍有同样性能。**本模型单节0.75 V是基准假设，不是实测极化曲线；0.70 V用于敏感性分析。若低温/高原工作点下降，需要替换输入重算。

### 3.2 功率与反应物方程

```text
Pstack = N × Vcell × I
5000 = ηDC × Pstack − Pblower − Pfan − Ppump − Pfixed
mH2,reaction = N × I × MH2 / (2F)
mH2,fresh = mH2,reaction / ηH2
mair = N × I × MO2 / (4F) × λair / 0.232
```

N=119，ηDC=0.96，ηH2=0.97，λair=2.2，固定辅助电功率100 W。97%是新鲜氢利用率假设，不是阳极流道计量比；若采用氢循环，还要增加循环装置损耗，若死端吹扫则需重新积分排氢。

鼓风机功耗用等熵压缩估计，入口取当地大气压，基准阴极总压升15 kPa，总效率50%。该压升需由滤芯、管路、加湿器、电堆和背压件分项替换；还需要膜两侧差压约束，不能据此直接设置阳极压力。

### 3.3 热管理与液路方程

```text
Qreaction,HHV ≈ N × I × (1.481 − Vcell)
Qcoolant = 0.85 × Qreaction,HHV + Ppump
mc × cp,c × (60−55) = Qcoolant
Δpc = 80 kPa × [液体体积流量 / (20 L/min)]²
Ppump = 液体体积流量 × Δpc / 0.30
```

1.481 V为热中性电压近似常数。85%热量进入冷却液、15%分配给尾气水焓和环境，是尚未测量的分配假设。避免把全部HHV热量与水蒸气焓重复计入。泵电功率保守计入液体，需实机热平衡修正。

暂用低温冷却液温热物性cp=3300 J/(kg·K)、ρ=1060 kg/m³；不等于已指定冷却液型号或确认−30℃黏度/电导率。二次阻力曲线只适合本次温热估算，不能外推到冷浸启动。

DC/DC损耗、风机/鼓风机电机热及电控热没有全部进入电堆冷却回路，应通过各自通风/散热独立排出。整机风道还需考虑热空气回流。

### 3.4 散热器方程

采用ε–NTU逆流基式并乘0.85布局修正，用于初步筛选，不代表实际交叉流散热器。

```text
体积风量 = 3 m/s × A
UA = 1000 W/(m²·K) × A
Qradiator = 0.85 × ε(NTU,Cr) × Cmin × (60−35)
Pfan = 180 Pa × 体积风量 / 0.35
```

这里1000 W/(m²·K)是以**迎风面积**归一的假设UA系数，不是翅片表面对流换热系数。厚度、翅片密度、空气阻力与UA实际相互耦合，必须用同一台散热器性能数据替换，不能独立拼最优参数。

## 5. 纯气态储氢容量与外包络

使用CoolProp真实氢气状态方程，不用35 MPa理想气体近似：

```text
ρfill = ρH2(15℃, 35 MPa绝压) = 23.995 kg/m³
ρresidual = ρH2(−30℃, 2 MPa绝压) = 1.969 kg/m³
musable,required = (0.32051×4 + 0.03) / 0.90 = 1.458 kg
Vwater ≥ musable,required / (ρfill−ρresidual) = 66.2 L
```

模型按10 L档位向上取整得到70 L。考虑单项不利工况需约73～75 L，本版**布局优先按2×40 L、总80 L预留**，并非已找到或确认某型号气瓶。

总80 L在上述状态下约存1.920 kg氢，可用约1.762 kg。双瓶允许隔离维护与分阶段使用；不意味着可以在带压连接状态直接拆卸。

35 MPa、15℃装满后，同密度冷浸−30℃压力约29.27 MPa，升温至50℃约39.42 MPa。该计算用于暴露温度压力关联，不能解释为允许超额充装。实际允许充装质量、温度补偿和安全附件按认证瓶文件确定。

### 概念尺寸的来源

只做空间估算：假定外径320 mm、容量几何内径280 mm、半球端封几何，再给阀端/端部140 mm长度余量，40 L单瓶外包长度约883 mm。

**320×约885 mm是占位包络，不是压力容器设计图。**内外径差只是几何占位，不代表通过应力核算得到的壁厚，也不能据此制造气瓶。最终采用认证商品瓶的外形、质量、阀口与安装约束。

## 7. 管路、接头与传感器

按基准流量限定流速，冷却液1.5 m/s时内径约15.9 mm，先研究16～19 mm内径；空气入口10 m/s时内径约34.5 mm，先研究35～40 mm内径。管网压降还需逐段加入长度、粗糙度、弯头、阀和热交换器阻力。

氢管不能只按氢耗选尺寸：需要同时核对调压瞬态、吹扫峰值、连接标准、最小残压及允许压降。高压段采用合格氢用高压管件组合，低压段单独定义等级。暂不指定材料牌号、壁厚或弯曲半径为已验证值。

参考水冷堆阳极1/2″、阴极和冷却3/4″只表明名义尺寸，不足以判断BSP/NPT或密封形式。每个接头需供应商图纸确认；低压冷却软管也不能用于高压氢路。

| 测量/执行对象 | 第一版接口原则 |
|---|---|
| 气瓶压力 | 选定量程后优先4–20 mA或受支持的数字接口；端口与压力等级随瓶阀组 |
| 低压氢/阴极压力、差压 | 两侧压力及差压都要能验证；量程由堆厂许可窗口确定 |
| 温度 | 堆进出口、环境、关键排水部位；RTD接专用采集模块，不直接假定接CAN |
| 冷却/空气流量 | 输出形式、低温量程和压降由型号确定 |
| CVM与BMS | 获取供应商协议与故障码后接控制器；不假定裸堆CVM自带CAN |
| 氢探测器 | 顶部积聚风险位置与实际通风路径共同确定；安全联锁不只依赖上位机通信 |
| 阀、泵、风机 | 电源、PWM/CAN/模拟量命令、转速反馈和失电状态分别记录 |

每个端口/传感器进入CAD前必须填料号、尺寸、信号、供电、引脚、密封、维护空间和低温范围。

## 8. 冷启动独立预算：尚未闭合

稳态可行不能推出冷启动成功。−30℃至0℃，忽略散热、产水结冰和熔化潜热时：

| 需升温等效热容 | 120 s热功率下界 | 热量 |
|---|---:|---:|
| 5 kJ/K | 1.25 kW | 0.042 kWh |
| 20 kJ/K | 5.0 kW | 0.167 kWh |
| 70 kJ/K | 17.5 kW | 0.583 kWh |

三行都是未知热容的扫描，不能根据28 kg堆重任取一行。应取得电堆组成热容、最小小循环液量及冷启动电化学数据。

若电池在120 s内承担5 kW负载和0.8 kW启动辅机，母线需求约0.193 kWh。按转换效率0.9、SOC使用窗口0.6、低温可用能量系数0.6的假设，名义容量至少约0.60 kWh；因此先给0.8～1.2 kWh占位。功率能力需独立核验，6 kW对小电池是高倍率要求。

若同时增加5 kW电加热，名义能量下界升至约1.11 kWh，母线瞬时功率10.8 kW；若17.5 kW加热，名义容量约2.40 kWh、瞬时23.3 kW。现有6 kW双向DC/DC预算不再适用。不能在模型外默默增加加热器。

应分别输出：电池首次供电时间、电堆首次稳定发电时间、电堆单独维持5 kW净输出时间、启动氢耗、电耗和冰库存。到0℃不作为无冰堵的充分条件。

## 10. 下一步必须补齐的数据

1. 7～10 kW采购平台在60～65℃、低压/高原的极化曲线、允许差压、气体露点及低温资格；
